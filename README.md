# incident-investigations

**Two reproducible SOC case studies using synthetic evidence.** Учебные расследования: исходные события, проверяемая временная линия, гипотезы, решения об эскалации и явно обозначенные пробелы в доказательствах.

| Кейс | Материал | Основной вопрос |
|---|---|---|
| [01 — Подозрительные входы](CASE-01.md) | 13 событий аутентификации | Что доказывает успешный вход после серии ошибок? |
| [02 — Изменения на Windows-хосте](CASE-02.md) | 6 Windows Security событий | Как связать аккаунт, права, службу и очистку лога без ложной корреляции? |

## Проверить за минуту

Python 3.11+, внешних зависимостей нет:

```bash
git clone https://github.com/assnce/incident-investigations.git
cd incident-investigations
python replay.py --check
python -m unittest -v
```

`python replay.py` перестраивает `01-authentication-timeline.md`, `02-windows-changes-timeline.md` и соответствующие `*-findings.json` из evidence. `--check` проверяет их без перезаписи. Ожидаются 19 событий и по одному основному finding в каждом кейсе. В первом кейсе отдельный паттерн нескольких пользователей разобран вручную; воспроизводимый запрос выделяет именно success-after-failures.

## Происхождение и достоверность

Все события **сгенерированы для лаборатории**, не получены из production или реального расследования. Используются тестовые адреса из документальных диапазонов, вымышленные аккаунты и хосты. Windows-события представлены как нормализованные JSON-записи, а не оригинальные EVTX. Файлы согласований — тоже часть синтетического сценария.

`evidence-manifest.json` фиксирует SHA-256 исходных файлов. Это проверка воспроизводимости внутри репозитория, **не доказательство подлинности журналов и не forensic chain of custody**. Классификация событий в отчётах основана на предоставленных данных, а не на скрытой «истине» сценария.

## Как устроен разбор

1. Исходный сигнал и границы задачи.
2. Ссылки на конкретные event IDs.
3. Проверяемые гипотезы и альтернативные объяснения.
4. Вывод отдельно от предположения.
5. Недостающие данные, приоритет и следующий шаг.
